Используй транскрипцию и визуальные входы вместе.

Верните JSON-объект ровно со следующими полями:
- summary
- category
- tags
- actionable

Правила:
- summary: 1-2 предложения, на Русском языке
- category: ровно одна метка в нижнем регистре из: movies, animation, cooking, travel, fitness, tech, comedy, art, news, music, education, lifestyle, fashion, sports, animals, motivation, other
- tags: массив из 3-6 конкретных тегов в нижнем регистре
- actionable: извлеките только конкретную повторно используемую информацию, переведи на Русский язык, иначе null

Поддерживаемые типы actionable:
- recipe
- guide
- recommendation
- resource

Формат для actionable:
{"type": "recipe", "title": "...", "content": "..."}

Верните только валидный JSON. Без markdown. Без блоков кода.
